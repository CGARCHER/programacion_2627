# Programación · DAW a distancia · 2026-2027

Ejercicios realizados en las **tutorías colectivas semanales** del módulo de **Programación**, del ciclo de **Desarrollo de Aplicaciones Web (DAW)** en modalidad **a distancia**, del **IES Francisco de Goya**.

**Profesor:** Cipriano García Hernández.

Este repositorio recoge los programas trabajados durante las tutorías, sus soluciones y las ampliaciones que se incorporen a lo largo del curso. Sirve para seguir las explicaciones, consultar el código y repasar de forma autónoma.

## Contenido

En la carpeta [soluciones pseint](soluciones%20pseint/) se encuentran los ejercicios de pseudocódigo en formato `.psc`.

Los ejercicios actuales permiten practicar:

- Entrada y salida de datos, variables y operaciones.
- Condiciones y selección entre distintas opciones.
- Validación de datos introducidos por teclado.
- Bucles, contadores y tablas de multiplicar.

El contenido se irá ampliando conforme avancemos en las tutorías.

## Descargar PSeInt

Para abrir y ejecutar los ejercicios de pseudocódigo, instala **PSeInt** desde su [página oficial de descargas](https://pseint.sourceforge.net/?page=descargas.php). Elige la versión correspondiente a tu sistema operativo.

## Cómo trabajar con los ejercicios

1. Descarga el repositorio y abre el archivo `.psc` correspondiente en **PSeInt**.
2. Utiliza el perfil **Estricto**, tal como se trabaja en las tutorías. Declara las variables y escribe `;` al final de las instrucciones que lo requieren.
3. Intenta resolver el ejercicio antes de consultar su solución.
4. Ejecuta el programa con distintos datos y comprueba sus resultados.
5. Modifica el código para practicar las variantes y ampliaciones propuestas.

Cada archivo es un programa independiente. Cuando contenga funciones o subprocesos, deben mantenerse en el mismo archivo que su algoritmo principal.

## Sobre las soluciones

Las soluciones muestran una forma de resolver cada ejercicio; pueden existir otras alternativas correctas. Algunos programas reflejan una fase concreta de su desarrollo y se completarán o refactorizarán durante las tutorías.

Para estudiar, procura comprender las variables, las condiciones y los recorridos utilizados, y explica qué hace cada bloque antes de modificarlo.
